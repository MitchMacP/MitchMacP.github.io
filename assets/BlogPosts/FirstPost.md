## Finishing University

Currently in the last few weeks of my master's. Hoping to release my dissertation project fully once that is finished.

For my dissertation, I made an External Debug Tool for Unity. I mainly got the idea from when I was modding Lethal Company, as working out if a feature was working proved super difficult when being unable to see what's actually happening within the build. So essentially, this tool connects to a Unity game build and lets the user view all debug logs, GameObjects in each scene, and the Components of a GameObject.
